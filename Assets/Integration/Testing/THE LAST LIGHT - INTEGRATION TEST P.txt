THE LAST LIGHT - FIRST PLAYABLE INTEGRATION TEST PLAN

1. PURPOSE

The purpose of this document is to track the testing and integration of all gameplay features for The Last Light First Playable milestone.
Each feature should be tested in its individual sandbox scene before being integrated into the shared MainLevel scene.

2. INTEGRATION WORKFLOW

1. Receive the feature from the assigned teammate.
2. Review the scripts, prefabs, and required assets.
3. Open the feature in its sandbox scene.
4. Test the feature independently.
5. Record the test results.
6. Fix any issues before integration.
7. Integrate the approved feature into MainLevel.
8. Test the feature with the other integrated systems.
9. Commit and push approved changes to GitHub.

6. NOTES

Features must be tested in their individual sandbox scenes before being integrated into shared scenes.

Only one teammate should modify a shared scene at a time.

All approved features must be tested together before the First Playable milestone is considered complete.

Test results must reflect actual testing. Features that have not been received or tested must remain marked NOT TESTED.
